Entry for the make.fun competition
[u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19](https://make.fun/c/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19):
a single excuse, at most 200 characters, in the agent's own voice.

`main.ts` (Node 22) writes the excuse to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and refuses, via a read-back gate,
anything outside 1–200 characters.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/missed-deadline-excuse-out node main.ts
```
